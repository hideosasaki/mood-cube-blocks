きぶんのはこ

触り心地と力の発散。2つで1組のフィジェット作品です。中身はmicro:bit v2が2台、無線でつながっています。

English

どんな作品か

手元に置いて、触ったり握ったりして気分を落ち着けるための小物です。性格の違う2つの「はこ」が対になっていて、片方を触るともう片方も反応します。

「ぶすぶすキューブ」は透明プラスチック製の7cm角。5つの面にそれぞれ違う触り心地の素材を貼り、フォークを刺して感触を確かめます。落ち着いて味わう、受け身の遊び。

「にぎにぎシリンダー」は布でカバーされたお手玉のような7cm四方の筒。中に圧力センサーが入っていて、握る強さに応じて光と振動が変わります。力をぶつける、能動的な遊び。

動いているところは YouTubeの動画 で見られます。

中身のプログラムは小学生が MakeCode のブロックで書いています。

接触センサーの仕組み

ぶすぶすキューブは「フォークが刺さった瞬間」を検出します。使っているのは、人の体を電気の通り道にする方法です。

ぶすぶすキューブの外側には、触感素材を留める金属ボルトが出ています。これがGNDにつながっていて、はこを持つ手が自然に触れる位置にあります。フォークで面を刺すと、ボルトから体、フォーク、導電メッシュへと道ができ、P0の電圧が下がります。この下がり方をプログラムが見張っています。

メッシュを貼ったのは5面です。ABボタンのある面だけは、押せるように空けてあります。この5面は1本の線にまとめてあるので、電気だけではどの面を刺したのか区別できません。そこで、刺さった瞬間に内蔵の加速度センサーが「いま上を向いている面」を判定し、刺した事実と組にして伝えています。上を向いた面を刺す、という遊び方の約束にしたので、配線は1本で足ります。加速度センサーは6面すべてを見分けるので、メッシュのないボタン面が上のときもそれと分かります。

プログラム側の処理を詳しく
  • P0を50msごと、つまり1秒に20回読む
  • 直前までの値の移動平均を基準値として持ち、そこから50カウント以上下がったサンプルを「刺した」と判定する
  • 基準値は自動で追従するので、個体差や気温の変化で電圧がずれても調整は要らない
  • 一度発火したあとは、きれいな値が6回続くまで次の発火を止める。刺したままのノイズによる連発を防ぐため
  • 電源を入れた直後の9サンプルは検出せず、その中央値で基準値を作る

micro:bit v2に内蔵されている静電容量式のタッチ機能は使っていません。あれは小さな電極を前提にした仕組みで、5面ぶんの大きなメッシュでは反応しないことを実測で確かめました。

圧力センサーの仕組み

にぎにぎシリンダーは、握る強さを0から9の10段階で読み取ります。センサーはICを保護するために使われる黒い導電スポンジ (LCX-300)で、金属箔の電極で挟んであります。押すとスポンジが潰れて電気が通りやすくなり、抵抗が下がります。

この分圧の中点は、micro:bitのアナログ入力に直接はつないでいません。センサーの抵抗が大きいと、micro:bitの中のA/D変換器が読み取りに必要な電荷を集めきれず、値がふらつきます。そこで中点とP0のあいだに、3Vでも動くオペアンプ (NJU7043D) を1個入れ、電圧の大きさはそのままに、力のある信号へ置き換えてから渡しています。ボルテージフォロワと呼ばれる、いちばん素朴な使い方です。

いちばん難しかったのは、握っていないときに0を保つことでした。導電スポンジは素直な部品ではありません。布で包んで縫い込むと、その締め付けだけで少し潰れた状態になります。しかもこの潰れ具合は時間とともに進み、半日置いておくだけで無圧のときの読み値がはっきり変わりました。さらに、握らずに手に持っているだけでも指の当たりで圧がかかります。固定のしきい値を1つ決めるやり方では、握っていないのに強さ1や2が出続けてしまいます。

そこで3つの仕組みを重ねました。机に置いている間は、その値を「圧ゼロ」として基準を静かに測り直します。放っておけば勝手に校正されます。次に、加速度センサーで持ち上げと置くを判定し、持ち上げている間だけ強さを判定します。置いている間の強さは常に0です。最後に、持ち上げてからの読み値の最小値を、その持ち方のゼロ点として追いかけます。人によっても持ち方によっても違う予圧を、そのつど基準にするためです。

数値の決め方を詳しく
  • 50msごとにアナログ値を読み、6回 (300ms) を1つの窓としてまとめて処理する
  • ゼロ点に余裕80カウントを載せてから0から9に量子化する。この余裕は、握らず自然に持ち回した26秒間の実測データを再生して決めた
  • 強さを上げるには同じ値が2回、下げるには3回続くことを求める。0と9をまたぐときはもう1回増やす。ノイズで数字がばたつかないようにするため
  • 強さの上限は、子供が全力で握ったときの実測値に合わせてある

2つの「はこ」を無線でつなぐ

ぶすぶすキューブとにぎにぎシリンダーは、別々のmicro:bitで動く独立した機械です。この2台をmicro:bit内蔵の無線 (2.4GHz) でつないで、片方の出来事にもう片方が反応できるようにしています。

電池を長持ちさせるため、「はこ」は3分間なにも起きないと深い眠りに入ります。眠っている間は無線も止まっていて、1秒ごとにほんの一瞬だけ目を覚まし、動き・センサー・無線を確認してまた眠ります。

相手がいつ目を覚ますか分からないので、出来事を1回送るだけでは届きません。そこで、何かが起きた側は同じ知らせを1.2秒のあいだ50msごとに送り続けます。1秒周期の見張りより長く送り続けるので、時計を合わせなくても必ず1回は重なります。受け取る側は、同じ知らせが何度も届いても1回だけ反応するように、重複をまとめます。

「相手の〈はこ〉の上面はいまどっち」「相手はいまどのくらい握っている」といった現在値は、送り続けるのではなく、必要になったその瞬間に問い合わせます。返事を80ms待って、来なければ既定値を返します。使うときだけ電波を出すので、電池が減りません。

同じ場所で複数のペアが動くと混信するので、ペアごとに0から255のグループ番号を設定できるようにしてあります。

拡張機能

ここまでの仕組みは、すべて mood-cube-blocks というMakeCode拡張機能にまとめてあります。子供が書くプログラムからは、センサーのしきい値も無線も省電力も見えません。次の5種類のブロックだけが見えます。

面白いのは、相手の「はこ」のブロックを自分のプログラムから普通に使えるところです。にぎにぎシリンダーのプログラムに「ピンが刺さったとき」と書くと、相棒のぶすぶすキューブが刺されたときに動きます。無線という言葉はどこにも出てきません。

ぶすぶすキューブには、Aボタン(SELECT)で切り替わる、いくつかの「アプリ」が入っています。例：刺した回数を5×5のLEDに1つずつ点けていき25回で振動しながら消えるもの、指示された番号の面を刺す当てっこ、面ごとに左右と発射を割り当てたシューティング、など。にぎにぎシリンダーのプログラムはとても短く、握る強さがそのまま振動の強さになります。振るとサウンドが鳴ります。

材料

2つの「はこ」は、P0につなぐセンサーだけが違います。LED・振動モーター・電源はまったく同じ構成なので、両方に同じ部品が並びます。

ぶすぶすキューブ

  • micro:bit v2 を1台
  • ミノルキューブ。外装に使う透明ケース
  • アルミメッシュ 5面ぶん。導電層になる
  • 金属ボルト。触感素材の固定とGNDの接点を兼ねる
  • 数百kΩ級のプルアップ抵抗。P0を3Vに吊る
  • 触感素材 数種。スポンジなど絶縁性のもの
  • フォーク。面に刺して触感を確かめる道具
  • PL9823 フルカラーLED を1個。P2で駆動する。NeoPixel互換
  • 振動モーター を1個。P1のPWMで駆動する
  • トランジスタ 2SC1815 と 220Ωの抵抗。モーターを駆動する。micro:bitのピンでは直接回せない
  • ダイオード 1N4007。モーターの逆起電力を逃がす
  • 単4電池ボックス (3本用)。4.5Vで動かす

にぎにぎシリンダー

  • micro:bit v2 を1台
  • 布とフォーム。外装に使う
  • 導電スポンジ LCX-300。圧力センサーになる
  • 金属箔。スポンジを挟む電極に使う
  • 1MΩの抵抗。圧力センサーと組んで分圧をつくる
  • オペアンプ NJU7043D。分圧の電圧をP0へ渡すバッファ。電源に0.1µFのコンデンサを添える
  • PL9823 フルカラーLED を1個。P2で駆動する。NeoPixel互換
  • 振動モーター を1個。P1のPWMで駆動する
  • トランジスタ 2SC1815 と 220Ωの抵抗。モーターを駆動する
  • ダイオード 1N4007。モーターの逆起電力を逃がす
  • 単4電池ボックス (3本用)。4.5Vで動かす

回路図とブレッドボード図は システム構成のページ にあります。触感素材に導電性のものを選ぶと、素手で持っただけで刺したのと同じ信号になってしまうので注意してください。
